# 제어 센터 (Console)

**제어 센터(Console)**는 CoPaw의 내장 웹 관리 인터페이스입니다. `copaw app` 명령어를 실행한 후, 브라우저에서 `http://127.0.0.1:8088/`에 접속하여 이용할 수 있습니다.

**제어 센터에서 할 수 있는 일:**

- CoPaw와 실시간 대화
- 메시지 채널 활성화/비활성화
- 모든 채팅 세션 확인 및 관리
- 예약 작업(Cron) 관리
- CoPaw의 페르소나 및 행동 설정 파일 편집
- 스킬(Skills)을 켜고 꺼서 CoPaw의 능력 확장
- MCP 클라이언트 관리
- 실행 환경 설정 수정
- LLM 제공자 설정 및 모델 선택
- 도구 실행에 필요한 환경 변수 관리

왼쪽 사이드바에는 **채팅**, **제어**, **에이전트**, **설정**의 네 그룹으로 나뉜 모든 기능이 나열되어 있습니다. 각 항목을 클릭하여 페이지를 전환할 수 있습니다. 아래에서 각 기능의 조작 방법을 차례대로 소개합니다.

> **제어 센터가 보이지 않나요?** 프론트엔드가 빌드되었는지 확인해 주세요. 빌드 방법은 [CLI](./cli) 문서를 참조하세요.

---

## 채팅 (Chat)

> 사이드바: **채팅 → 채팅**

사용자와 CoPaw가 직접 대화하는 공간입니다. 제어 센터에 접속하면 기본으로 표시되는 페이지입니다.

![채팅](https://img.alicdn.com/imgextra/i4/O1CN01Q0kWkE1WlHCNXeUlb_!!6000000002828-2-tps-3822-2070.png)

**메시지 보내기:**
하단 입력창에 내용을 입력하고 **Enter**를 누르거나 전송 버튼(↑)을 클릭하면 CoPaw가 실시간으로 답변합니다.

**새 채팅 시작:**
채팅 페이지 사이드바 상단의 **+ New Chat** 버튼을 클릭하여 새로운 대화를 시작할 수 있습니다. 각 세션은 독립된 대화 기록을 보관합니다.

**채팅 전환:**
채팅 사이드바에서 원하는 세션 이름을 클릭하면 해당 세션의 이전 메시지 기록이 로드됩니다.

**채팅 삭제:**
세션 항목 우측의 **···** 버튼을 누른 뒤 나타나는 **휴지통** 아이콘을 클릭하여 삭제합니다.

## 채널 (Channels)

> 사이드바: **제어 → 채널**

여기에서 각 메시지 채널(딩딩, 페이슈, Discord, QQ, iMessage, Console)의 활성화 여부와 인증 정보를 관리합니다.

![채널](https://img.alicdn.com/imgextra/i2/O1CN01LwWGzl28NPxvKFhtk_!!6000000007920-2-tps-3822-2070.png)

**채널 활성화:**

1. 설정하려는 채널 카드를 클릭합니다.
2. 우측에서 설정 패널이 슬라이드되어 나타나면 **Enable** 스위치를 켭니다.

   ![채널 설정](https://img.alicdn.com/imgextra/i2/O1CN010Idje31Gqk4a5SCuA_!!6000000000674-2-tps-3822-2070.png)

3. 해당 채널에 필요한 인증 정보를 입력합니다(채널마다 다름):

   | 채널         | 필요 입력 필드                                       |
   | ------------ | ---------------------------------------------------- |
   | **딩딩**     | Client ID, Client Secret                             |
   | **페이슈**   | App ID, App Secret, 암호화 키, 검증 토큰, 미디어 디렉토리 |
   | **Discord**  | Bot Token, HTTP 프록시, 프록시 인증                  |
   | **QQ**       | App ID, Client Secret                                |
   | **iMessage** | 데이터베이스 경로, 폴링 간격                          |
   | **Console**  | _(스위치만 켜기)_                                     |

4. **저장(Save)**을 클릭하면 몇 초 내에 자동으로 반영됩니다(재시작 불필요).

**채널 비활성화:**
해당 설정 패널에서 **Enable** 스위치를 끄고 **저장**을 누릅니다.

> 각 플랫폼의 인증 정보 획득 방법은 [채널 설정](./channels) 문서를 참조하세요.

## 세션 (Sessions)

> 사이드바: **제어 → 세션**

모든 채널에서 발생한 채팅 세션을 확인하고, 필터링하거나 정리할 수 있습니다.

![세션](https://img.alicdn.com/imgextra/i3/O1CN01wqN6uN23XQXhCwHiq_!!6000000007265-2-tps-3822-2070.png)

**세션 검색:**
검색창에 사용자 이름을 입력하거나 드롭다운 메뉴로 채널별 필터링을 할 수 있습니다. 목록은 즉시 업데이트됩니다.

**세션 이름 수정:**
해당 행의 **편집(Edit)** 버튼 클릭 → 이름 수정 → **저장** 클릭.

**세션 개별 삭제:**
해당 행의 **삭제(Delete)** 버튼 클릭 → 팝업창에서 확인.

**일괄 삭제:**
삭제하려는 행을 체크 → 상단에 나타나는 **일괄 삭제** 버튼 클릭 → 확인.

## 예약 작업 (Scheduled Jobs)

> 사이드바: **제어 → 예약 작업**

일정한 시간에 맞춰 자동으로 실행되는 CoPaw의 작업을 생성하고 관리합니다.

![예약 작업](https://img.alicdn.com/imgextra/i1/O1CN01B83KJC1LptPwniEDa_!!6000000001349-2-tps-3822-2070.png)

**새 작업 생성:**

> 예약 작업 생성이 되지 않는 경우 [FAQ](https://copaw.agentscope.io/docs/faq)의 **예약 작업 오류 해결 가이드**를 참조하세요.

예약 작업을 생성하는 **가장 쉬운 방법은 CoPaw에게 직접 말하는 것**입니다. 예를 들어 딩딩에서 물 마시기 알림을 받고 싶다면, CoPaw에게 "5분마다 물 마시라고 알려주는 예약 작업을 만들어줘"라고 요청하세요. 생성이 완료되면 제어 센터에서 확인할 수 있습니다.

직접 생성하는 방법은 다음과 같습니다:

1. **+ Create Job** 버튼을 클릭합니다.

   ![예약 작업 생성](https://img.alicdn.com/imgextra/i1/O1CN012irZqr1S0mWpCHgoM_!!6000000002185-2-tps-3822-2070.png)

2. 양식을 작성합니다:
   - **기본 정보** —— 작업 ID(예: `job-001`), 이름(예: "데일리 요약")을 입력하고 스위치를 활성화합니다.
   - **스케줄링** —— Cron 표현식(예: `0 9 * * *` = 매일 오전 9시)을 입력하고 시간대를 선택합니다.
   - **작업 유형 및 내용** —— **Text**(고정 메시지 전송) 또는 **Agent**(CoPaw에게 질문하고 답변 전달) 중 선택한 후 내용을 입력합니다.
   - **전송 대상** —— 대상 채널(예: Console, 딩딩), 대상 사용자, 전송 방식(**Streaming** = 실시간 전송, **Final** = 완료 후 한꺼번에 전송)을 선택합니다.
   - **고급 옵션** —— 최대 동시 실행 수, 타임아웃 등을 필요에 따라 조정합니다.
3. **저장**을 클릭합니다.

**작업 편집:**
행의 **편집** 버튼 클릭 → 필드 수정 → **저장**.

**작업 활성/비활성:**
행의 스위치를 클릭하여 켜거나 끕니다.

**즉시 실행:**
**Run Now** 클릭 → 확인. 해당 작업이 즉시 1회 실행됩니다.

**작업 삭제:**
**삭제** 버튼 클릭 → 확인.

## 워크스페이스 (Workspace)

> 사이드바: **에이전트 → 워크스페이스**

CoPaw의 페르소나와 행동을 정의하는 파일(SOUL.md, AGENTS.md, HEARTBEAT.md 등)을 브라우저에서 직접 편집할 수 있습니다.

![워크스페이스](https://img.alicdn.com/imgextra/i3/O1CN017nvwCe26Ucy89Kktq_!!6000000007665-2-tps-3822-2070.png)

**파일 편집:**

1. 목록에서 파일 이름을 클릭합니다.
2. 편집기에 내용이 나타나면 수정합니다.
3. **저장**을 클릭하면 즉시 반영되며, **재설정(Reset)**을 누르면 수정을 취소하고 다시 로드합니다.

**데일리 메모리 확인:**
`MEMORY.md` 파일이 있다면 옆의 **▶** 화살표를 눌러 날짜별 항목을 펼치고 내용을 확인하거나 수정할 수 있습니다.

**전체 워크스페이스 다운로드:**
**다운로드** 버튼(⬇)을 클릭하면 워크스페이스 전체가 `.zip` 파일로 저장됩니다.

**워크스페이스 업로드/복구:**
**업로드** 버튼(⬆) 클릭 → `.zip` 파일 선택(최대 100MB). 현재 워크스페이스 파일이 대체됩니다. 다른 기기로 이전하거나 백업에서 복구할 때 유용합니다.

## 스킬 (Skills)

> 사이드바: **에이전트 → 스킬**

PDF 읽기, 문서 작성, 뉴스 검색 등 CoPaw의 능력을 확장하는 스킬들을 관리합니다.

![스킬](https://img.alicdn.com/imgextra/i1/O1CN018YXGth1JcUb7KAQ7S_!!6000000001049-2-tps-3822-2070.png)

**스킬 활성화:**
스킬 카드 하단의 **Enable** 링크를 클릭하면 즉시 활성화됩니다.

**상세 정보 확인:**
스킬 카드를 클릭하면 전체 설명을 볼 수 있습니다.

**스킬 비활성화:**
**Disable** 링크를 클릭하면 즉시 비활성화됩니다.

**Skill Hub에서 가져오기:**

1. **Import Skill**을 클릭합니다.
2. 스킬 URL을 입력하고 클릭합니다.
3. 완료되면 목록에서 확인 및 활성화할 수 있습니다.

   ![스킬 가져오기](https://img.alicdn.com/imgextra/i3/O1CN01CuA4Yd1tguaRzXK9x_!!6000000005932-2-tps-3822-2070.png)

**사용자 지정 스킬 생성:**

1. **Create Skill**을 클릭합니다.
2. 스킬 이름(예: `weather_query`)과 내용(Markdown 형식, `name`과 `description` 포함)을 입력합니다.
3. **저장**을 누르면 새 스킬이 목록에 추가됩니다.

   ![스킬 생성](https://img.alicdn.com/imgextra/i4/O1CN018JNLfg27xlmmq7FTM_!!6000000007864-2-tps-3822-2070.png)

**삭제:**
먼저 해당 스킬을 비활성화한 뒤, 카드에 나타나는 **🗑** 아이콘을 눌러 삭제합니다.

> 내장 스킬 설명 및 커스텀 스킬 작성법은 [스킬](./skills) 문서를 참조하세요.

## 모델 (Models)

> 사이드바: **설정 → 모델**

LLM 제공자를 설정하고 CoPaw가 사용할 모델을 선택합니다. 클라우드 서비스(API Key 필요)와 로컬 실행(API Key 불필요) 모델 모두 지원합니다.

![모델](https://img.alicdn.com/imgextra/i4/O1CN01s3hlCB1ieCT8O91Vi_!!6000000004437-2-tps-3822-2070.png)

### 클라우드 제공자

**제공자 설정:**

1. 원하는 제공자(ModelScope, DashScope 등) 카드의 **설정(Settings)** 버튼을 클릭합니다.
2. **API Key**를 입력합니다.
3. **저장**을 누르면 상태가 'Authorized'로 바뀝니다.
4. 사용자 정의 제공자를 추가하려면 우측의 **Add Provider**를 클릭하세요.

**권한 취소:**
설정 대화상자에서 **Revoke**를 클릭하면 저장된 API Key가 제거됩니다.

### 로컬 제공자 (llama.cpp / MLX)

보라색 **Local** 태그가 표시됩니다. 사용 전 백엔드 의존성(`pip install 'copaw[llamacpp]'` 또는 `pip install 'copaw[mlx]'`) 설치가 필요합니다.

**모델 다운로드:**

1. 로컬 제공자 카드의 **Models** 버튼 클릭.
2. **Download Model** 클릭 및 정보 입력:
   - **Repo ID**(필수) —— 예: `Qwen/Qwen3-4B-GGUF`
   - **File Name**(선택) —— 비워두면 자동 선택
   - **Source** —— Hugging Face 또는 ModelScope 선택
3. **Download** 클릭 및 완료 대기.

### Ollama 제공자

Ollama 데몬과 연동하여 모델을 동적으로 로드합니다.

**준비 사항:**
- [ollama.com](https://ollama.com)에서 Ollama 설치 및 실행
- SDK 설치: `pip install 'copaw[ollama]'`

**모델 다운로드:**
제공자 카드에서 **Download Model**을 클릭하고 모델명(예: `mistral:7b`)을 입력하여 다운로드합니다. 이 목록은 로컬 Ollama 앱과 자동 동기화됩니다.

### 활성 모델 선택

1. 상단 **LLM Configuration**의 **Provider** 드롭다운에서 활성화된 제공자를 선택합니다.
2. **Model** 드롭다운에서 사용할 모델을 선택합니다.
3. **저장**을 클릭합니다.

## 환경 변수 (Environment Variables)

> 사이드바: **설정 → 환경 변수**

도구 및 스킬 실행에 필요한 환경 변수(예: `TAVILY_API_KEY`)를 관리합니다.

![환경 변수](https://img.alicdn.com/imgextra/i2/O1CN01H5652Z1byAQQ3JVC4_!!6000000003533-2-tps-3822-2070.png)

**변수 추가:**
하단의 **+ Add Variable** 클릭 → 변수명과 값 입력 → **저장**.

**변수 편집:**
기존 항목의 **Value** 필드를 수정하고 **저장**을 누릅니다. (이름 수정은 삭제 후 재생성 필요)

**변수 삭제:**
우측의 **🗑** 아이콘 클릭 → 확인.
