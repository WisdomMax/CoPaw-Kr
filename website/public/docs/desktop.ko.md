**처음 실행 시 다소 시간이 걸릴 수 있습니다(시스템 사양에 따라 10~60초 이상).** 앱이 Python 환경을 초기화하고, 의존성 라이브러리를 로드하며, 웹 서비스를 시작하는 과정이 필요하므로 창이 나타날 때까지 잠시 기다려 주세요. 두 번째 실행부터는 더 빠르게 시작됩니다.

## Windows 사용 가이드

### 시스템 요구 사항

- **운영체제**: Windows 10 이상
- **아키텍처**: x64 (64비트)

### 설치 단계

1. **설치 파일 다운로드**
   [릴리스 페이지][releases]에서 `CoPaw-Setup-<version>.exe` 파일을 다운로드합니다.

2. **설치 프로그램 실행**
   `.exe` 파일을 더블 클릭하고 설치 마법사의 안내에 따라 설치를 완료합니다.
   - 기본 설치 경로: `C:\Users\<사용자명>\AppData\Local\CoPaw`
   - 설치가 완료되면 바탕 화면과 시작 메뉴에 바로가기가 생성됩니다.

### 실행 방법

설치가 완료되면 **두 종류의 실행 바로가기**가 생성됩니다:

#### **CoPaw Desktop** (일반 사용 권장)

- **특징**: 터미널 창 없이 조용히 실행되며 인터페이스가 깔끔합니다.
- **권장 상황**: 일반적인 사용 시, 기술 로그를 볼 필요가 없을 때.
- **실행 방법**: 바탕 화면이나 시작 메뉴의 "CoPaw Desktop" 아이콘을 더블 클릭합니다.
- **기술 설명**: VBScript 런처를 사용하여 백그라운드에서 Python 프로세스를 실행합니다.

#### **CoPaw Desktop (Debug)** (디버그 모드)

- **특징**: 터미널 창이 표시되며 실시간 실행 로그가 출력됩니다.
- **권장 상황**:
  - 문제 발생 시 오류 메시지를 확인해야 할 때
  - 개발 및 테스트 시
  - 버그 리포트 작성을 위해 로그가 필요할 때
- **실행 방법**: 시작 메뉴의 "CoPaw Desktop (Debug)" 아이콘을 더블 클릭합니다.
- **로그 내용**:
  - 앱 시작 정보
  - Python 오류 스택
  - API 호출 로그
  - Ctrl+C를 누르거나 창을 닫으면 앱이 종료됩니다.

### 자주 묻는 질문 (FAQ)

**Q: 앱을 실행했는데 아무런 반응이 없어요.**
A: "CoPaw Desktop (Debug)" 모드로 실행하여 터미널에 출력되는 오류 메시지를 확인해 보세요.

**Q: 어떻게 삭제하나요?**
A: Windows 설정 → 앱 → 설치된 앱 → "CoPaw Desktop" 찾기 → 제거

**Q: 설치 파일이 안전한가요?**
A:
- 앱이 **Microsoft 코드 서명**(연간 $200-800 비용)을 거치지 않아 Windows Defender SmartScreen 경고가 표시될 수 있습니다.
- 이는 정상적인 현상이며, "추가 정보" → "실행"을 클릭하여 진행하시면 됩니다.
- 코드는 완전히 오픈 소스이며, 빌드 과정은 GitHub Actions에서 투명하게 확인 가능합니다.

## macOS 사용 가이드

### 시스템 요구 사항

- **운영체제**: macOS 14 (Sonoma) 이상
- **아키텍처**:
  - ✅ **Apple Silicon (M1/M2/M3/M4)** - 권장, MLX 로컬 모델 가속 지원
  - ⚠️ Intel 칩 - 실행은 가능하나 MLX 가속 기능은 사용할 수 없음

### 설치 단계

1. **압축 파일 다운로드**
   [릴리스 페이지][releases]에서 `CoPaw-<version>-macOS.zip` 파일을 다운로드합니다.

2. **압축 해제**
   `.zip` 파일을 더블 클릭하여 압축을 풀면 `CoPaw.app` 앱이 나타납니다.

3. **응용 프로그램 폴더로 이동 (선택 사항)**
   `CoPaw.app`을 `/Applications` 폴더로 드래그하여 이동합니다.

### 첫 실행: 시스템 보안 제한 해제

#### 수동 승인이 필요한 이유

CoPaw 앱은 **Apple 개발자 서명 및 공증(Notarization)을 거치지 않았으므로**, macOS Gatekeeper가 기본적으로 실행을 차단합니다.

**서명을 하지 않은 이유:**
- 📋 개발자 서명에는 추가 비용과 절차가 소요되며, 향후 버전에 반영될 예정입니다.

**현재 영향:**
- ✅ **기능상 문제 없음**: 앱은 완전히 정상적으로 작동합니다.
- ⚠️ **최초 1회 수동 승인 필요**: 한 번만 설정하면 이후에는 정상적으로 실행됩니다.
- 🔒 **보안성**: 오픈 소스 코드로 감사 가능하며 빌드 과정이 투명합니다(CI/CD).

#### 차단 해제 방법

#### 방법 1: 우클릭으로 열기 (권장)

1. `CoPaw.app`을 **우클릭**(또는 Control + 클릭)합니다.
2. 메뉴에서 **"열기"**를 선택합니다.
3. 팝업 대화상자에서 다시 한 번 **"열기"** 버튼을 클릭합니다.
4. ✅ 이후에는 더블 클릭만으로 정상 실행되며 팝업이 뜨지 않습니다.

#### 방법 2: 시스템 설정에서 허용

여전히 차단될 경우:
1. **시스템 설정 → 개인정보 보호 및 보안**으로 이동합니다.
2. 아래로 스크롤하여 다음과 같은 메시지를 찾습니다:
   _"확인된 개발자가 아니기 때문에 'CoPaw' 사용이 차단되었습니다."_
3. **"확인 없이 열기"** 또는 **"허용"** 버튼을 클릭합니다.
4. 관리자 암호를 입력하여 승인합니다.

#### 방법 3: 터미널 명령어로 격리 해제

```bash
# 다운로드 격리 속성 제거
xattr -cr /Applications/CoPaw.app
```

⚠️ **주의**: 이 방법은 보안 검사를 완전히 건너뛰므로, 앱 출처를 완전히 신뢰할 때만 사용하세요.

### 🔍 권한 요청

처음 실행할 때 macOS에서 다음과 같은 권한을 요청할 수 있습니다:

- **데스크톱 파일 접근 권한**
  파일 관련 기능을 사용할 때 파일에 접근하기 위해 필요합니다.
  - **"허용"**을 클릭하여 정상적으로 사용하세요.
  - **"허용 안 함"**을 선택해도 실행은 가능하나 일부 기능이 제한될 수 있습니다.

### 실행 방법

#### 일반 실행 (더블 클릭)

- `CoPaw.app`을 더블 클릭하여 실행합니다.
- 앱은 백그라운드에서 실행되며 브라우저 창이 열립니다.
- 로그 저장 위치: `~/.copaw/desktop.log`

#### 터미널에서 실행 (실시간 로그 확인)

앱이 종료되거나 상세 로그가 필요한 경우:

```bash
# 앱 디렉토리로 이동
cd /Applications  # 또는 CoPaw.app이 있는 경로

# 환경 변수 설정 및 실행
APP_ENV="$(pwd)/CoPaw.app/Contents/Resources/env"
PYTHONPATH= PYTHONHOME="$APP_ENV" "$APP_ENV/bin/python" -m copaw desktop
```

**터미널 실행의 장점:**
- ✅ 모든 로그 출력을 실시간으로 확인 가능
- ✅ 전체 Python 오류 스택 확인 가능
- ✅ 디버깅 및 문제 제보에 용이
- ✅ `--log-level debug` 인자를 추가하여 더 상세한 정보 확인 가능

**로그 파일 확인:**
```bash
# 최근 실행 로그 확인
tail -f ~/.copaw/desktop.log
```

### 자주 묻는 질문 (FAQ)

**Q: 더블 클릭해도 아무 반응이 없어요.**
A:
1. `~/.copaw/desktop.log` 파일을 열어 오류 내용을 확인해 보세요.
2. 위에서 설명한 터미널 명령어로 실행하여 실시간 출력을 확인해 보세요.

**Q: "Apple에서 이 앱을 확인할 수 없습니다"라고 떠요.**
A: 위의 "시스템 보안 제한 해제" 단계를 따라해 주세요.

**Q: 어떻게 삭제하나요?**
A: `CoPaw.app`을 휴지통으로 버린 후, `~/.copaw` 설정 폴더를 삭제하세요.

**Q: Intel Mac에서도 사용 가능한가요?**
A: 실행은 가능하지만, MLX 모델 가속은 지원되지 않습니다(MLX는 Apple Silicon 전용).
