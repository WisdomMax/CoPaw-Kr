# 가시적 브라우저 (실제 창 열기) 가이드

기본적으로 **browser_use** 도구는 백그라운드(headless) 모드에서 실행되므로 브라우저 창이 나타나지 않습니다. 사용자가 명시적으로 **"진짜 브라우저 창을 열어줘"**, **"브라우저 화면을 보고 싶어"**, **"UI가 있는 브라우저"** 또는 **"보이는 브라우저"**를 요청할 때 이 스킬을 사용하세요. 먼저 **headed** 모드로 브라우저를 시작한 다음 필요한 작업을 수행합니다.

## 언제 사용하나요?

- 사용자가 다음과 같이 말할 때: "진짜 브라우저 열어줘", "화면이 보이는 브라우저 써줘", "브라우저 창을 보고 싶어", "백그라운드 말고 눈에 보이는 창으로 띄워줘"
- 사용자가 페이지 로딩, 클릭, 폼 입력 등의 과정을 직접 눈으로 확인하고 싶을 때 (시연, 디버깅, 학습)
- 사용자가 화면과 직접 상호작용해야 할 때 (예: 사람이 직접 해야 하는 로그인, 캡차 인증 등)

## 사용 방법 (browser_use 도구 이용)

1. **먼저 가시적 모드로 브라우저 시작**  
   **browser_use** 도구를 호출할 때 `action`을 `start`로 설정하고 **headed=true** 매개변수를 전달합니다:
   ```json
   {"action": "start", "headed": true}
   ```
   성공하면 실제 Chromium 브라우저 창이 화면에 나타납니다.

2. **이후 필요한 페이지 탐색 및 조작**  
   무두(headless) 모드와 사용법이 동일합니다. 예:
   - URL 열기: `{"action": "open", "url": "https://example.com"}`
   - 페이지 구조 가져오기: `{"action": "snapshot"}`
   - 클릭, 입력 등: `ref`나 `selector`를 사용하여 클릭(click)이나 타이핑(type) 수행

3. **가시적 브라우저 종료**  
   작업이 끝나면 다음을 호출하여 브라우저를 닫습니다: `{"action": "stop"}`

## 기본(무두) 모드와의 차이점

| 모드 | 시작 방법 | 브라우저 창 표시 여부 |
|----------|-----------------------------|--------------|
| 무두(Headless) 모드 | `{"action": "start"}` | 아니오 (백그라운드) |
| 가시적(Headed) 모드 | `{"action": "start", "headed": true}` | 예 (실제 창 표시) |

## 주의 사항

- 이미 브라우저가 실행 중인 경우, 먼저 `stop`을 호출한 뒤 `headed: true`로 다시 `start`해야 가시적 창으로 전환됩니다.
- 가시적 모드는 데스크톱 화면을 점유하며 그래픽 환경이 필요합니다. GUI가 없는 서버 환경에서는 사용이 불가능할 수 있습니다.
