당신의 AI 개인 비서; 매우 간편한 설치, 로컬 및 클라우드 모두 배포 가능; 다양한 채널 연동 및 손쉬운 기능 확장 지원.

> **핵심 능력:**
>
> **유비쿼터스 연결** — 딩톡(DingTalk), 페이슈(Lark), QQ, Discord, iMessage 등 다양한 채널을 CoPaw 하나로 필요에 따라 연결합니다.
>
> **당신의 제어** — 기억과 개인화 설정은 로컬 또는 클라우드 어디서든 당신이 직접 관리합니다. 예약된 작업과 협업 알림을 지정된 채널로 보냅니다.
>
> **Skills 확장** — 내장된 예약 작업, 커스텀 스킬 디렉토리를 통해 CoPaw가 자동으로 기능을 로드하며 특정 플랫폼에 종속되지 않습니다.
>
> <details>
> <summary><b>CoPaw로 무엇을 할 수 있나요?</b></summary>
>
> <br>
>
> - **소셜 미디어**: 매일 인기 포스트 요약(인스타그램, 스레드, Reddit 등), YouTube 신규 영상 요약.
> - **생산성**: 이메일 및 뉴스레터 핵심 내용을 딩톡/페이슈/QQ 등으로 푸시, 이메일 및 캘린더 정리.
> - **창의성과 구축**: 자기 전 목표를 말하면 자동 실행하여 다음 날 초안 완성; 기획부터 영상 제작까지 전 프로세스 지원.
> - **연구와 학습**: 최신 기술 및 AI 뉴스 추적, 개인 지식 베이스 검색 및 재활용.
> - **데스크톱과 파일**: 로컬 파일 정리 및 검색, 문서 읽기 및 요약, 대화 중 파일 요청.
> - **더 많은 탐색**: Skills와 예약 작업을 조합하여 당신만의 agentic app을 만드세요.
>
> </details>

## 빠른 시작

### pip 설치

Python 환경을 직접 관리하는 경우:

```bash
pip install copaw
copaw init --defaults
copaw app
```

브라우저에서 **http://127.0.0.1:8088/** 을 열어 콘솔을 사용하세요(CoPaw와 대화, 에이전트 설정). 딩톡, 페이슈, QQ 등 앱 내에서 대화하려면 [문서](https://copaw.agentscope.io/docs/channels)를 참고하여 채널을 연동하세요.

![Console](https://img.alicdn.com/imgextra/i4/O1CN01kUEGsC1XolpzIWdsu_!!6000000002971-2-tps-3822-2064.png)

### 스크립트 설치

Python을 수동으로 설정할 필요 없이 한 줄의 명령어로 자동 설치합니다. 스크립트가 uv(Python 패키지 관리자) 다운로드, 가상 환경 생성, CoPaw 및 의존성(Node.js 및 프론트엔드 리소스 포함) 설치를 자동으로 완료합니다. 주의: 일부 네트워크 환경이나 기업 보안 정책에 따라 사용이 제한될 수 있습니다.

**macOS / Linux:**

```bash
curl -fsSL https://copaw.agentscope.io/install.sh | bash
```

Ollama 지원이 필요한 경우:

```bash
curl -fsSL https://copaw.agentscope.io/install.sh | bash -s -- --extras ollama
```

여러 확장을 설치하려는 경우(예: Ollama + llama.cpp):

```bash
curl -fsSL https://copaw.agentscope.io/install.sh | bash -s -- --extras ollama,llamacpp
```

**Windows (CMD):**

```CMD
curl -fsSL https://copaw.agentscope.io/install.bat -o install.bat && install.bat
```

**Windows (PowerShell):**

```powershell
irm https://copaw.agentscope.io/install.ps1 | iex
```

> **참고**: 설치 프로그램은 uv 상태를 자동으로 확인하며, 설치되어 있지 않으면 자동 다운로드를 시도합니다. 자동 설치에 실패하면 화면의 안내를 따르거나 `python -m pip install -U uv`를 실행한 후 설치 프로그램을 다시 실행하세요.

## 데스크톱 앱 (Beta)

> **Beta 버전 안내**: 데스크톱 앱은 현재 베타 테스트 단계이며 다음과 같은 제한 사항이 있을 수 있습니다:
> - **호환성 테스트 미비**: 모든 OS 버전 및 하드웨어 구성에서 충분히 테스트되지 않았습니다.
> - **성능 문제 가능성**: 실행 속도, 메모리 점유율 등 최적화가 더 필요할 수 있습니다.
> - **기능 지속 업데이트 중**: 일부 기능이 불안정하거나 누락될 수 있습니다.

명령어 사용이 익숙하지 않다면 Python 환경 설정이나 명령어 실행 없이 CoPaw 데스크톱 앱 버전을 다운로드하여 사용할 수 있습니다.

#### 다운로드

[GitHub Releases](https://github.com/agentscope-ai/CoPaw/releases)에서 데스크톱 앱을 다운로드하세요:
- **Windows**: `CoPaw-Setup-<version>.exe`
- **macOS**: `CoPaw-<version>-macOS.zip` (Apple Silicon 권장)

#### 특징

- ✅ **제로 설정**: 다운로드 후 더블 클릭으로 바로 실행, Python 설치나 환경 변수 설정 불필요
- ✅ **크로스 플랫폼**: Windows 10+ 및 macOS 14+ 지원
- ✅ **시각화**: 브라우저 인터페이스 자동 실행, 주소 수동 입력 불필요
- ⚠️ **Beta 단계**: 기능 지속 개선 중, 피드백 환영

상세 사용법 및 문제 해결은 [데스크톱 앱 가이드](https://copaw.agentscope.io/docs/desktop)를 참고하세요.

## API Key

**클라우드 대규모 언어 모델**(DashScope, ModelScope 등)을 사용하려면 대화 시작 전 API Key 설정이 필수입니다. 유효한 Key가 없으면 CoPaw가 정상적으로 작동하지 않습니다. 자세한 내용은 [공식 문서](https://copaw.agentscope.io/docs/models#%E9%85%8D%E7%BD%AE%E4%BA%91%E6%8F%90%E4%BE%9B%E5%95%86)를 참고하세요.

**설정 방법:**

1. **콘솔 (권장)** — `copaw app` 실행 후 **http://127.0.0.1:8088/** → **설정** → **모델**. 제공업체 선택, **API Key** 입력 후 해당 제공업체와 모델을 활성화합니다.
2. **`copaw init`** — `copaw init` 실행 시 LLM 제공업체와 API Key 설정을 안내합니다.
3. **환경 변수** — DashScope 사용 시 터미널이나 작업 디렉토리의 `.env` 파일에 `DASHSCOPE_API_KEY`를 설정할 수 있습니다.

> **로컬 모델만 사용하시나요?** [로컬 모델](#로컬-모델)(llama.cpp 또는 MLX)만 사용한다면 API Key가 **필요하지 않습니다**.

## 로컬 모델

CoPaw는 API Key나 클라우드 서비스 없이 내 PC에서 대규모 언어 모델을 완전히 로컬로 실행할 수 있습니다. 자세한 정보는 [공식 문서](https://copaw.agentscope.io/docs/models#%E6%9C%AC%E5%9C%B0%E6%8F%90%E4%BE%9B%E5%95%86llamacpp--MLX)를 확인하세요.

| 백엔드 | 적용 시나리오 | 설치 |
| --- | --- | --- |
| **llama.cpp** | 크로스 플랫폼 (macOS / Linux / Windows) | `pip install 'copaw[llamacpp]'` 또는 `bash install.sh --extras llamacpp` |
| **MLX** | Apple Silicon (M1/M2/M3/M4) | `pip install 'copaw[mlx]'` 또는 `bash install.sh --extras mlx` |
| **Ollama** | 크로스 플랫폼 (Ollama 서비스 실행 필요) | `pip install 'copaw[ollama]'` 또는 `bash install.sh --extras ollama` |

설치 후 **콘솔** 인터페이스에서 로컬 모델을 다운로드하고 관리할 수 있습니다.

## 왜 이름이 CoPaw인가요?

CoPaw는 '당신의 파트너인 작은 발바닥'(co-paw)이라는 뜻과 함께, **Co Personal Agent Workstation**(협업 개인 에이전트 워크스테이션)이라는 의미를 담고 있습니다. 차가운 도구가 아니라 언제든 도와줄 준비가 된 따뜻한 '작은 발바닥'처럼, 당신의 디지털 생활에서 가장 호흡이 잘 맞는 동반자가 되기를 희망합니다.
